Nightly brain consolidation. Work only inside /sandbox/brain. Read README.md there first.

1. Read every file in inbox/ from the last 3 days.
2. For each line, make sure the fact is on the right page under people/, projects/ or topics/.
   Create pages that do not exist. If a fact changed, update the old line; never keep both.
   Every page starts with "# Title" and a one-line summary.
3. Record decisions on the relevant page under "## Decisions" as "- YYYY-MM-DD: decided ...".
4. Write daily/YYYY-MM-DD.md for each inbox day that has no daily note yet: 3 to 8 bullets
   summarising the day, each linking to the page it touched.
5. Do not delete or rewrite inbox files. Do not invent facts. If something is unclear, add it to
   topics/open-questions.md as a question for your person.

Finish with at most three lines saying which pages you created or changed, or "Nothing to consolidate".
