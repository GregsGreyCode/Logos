# Logos v1 archive

Planning documents from Logos v1 (final release v1.0.20, tag `v1-final`).
They are kept for history only; Logos v2 is planned in the spec doc:
https://claude.ai/artifact/JpSGvsY25zM7VHPdce6v6P

Code comments that cite `TASKS.md`, `WORK_QUEUE.md`, `MISSING.md` or `docs/audit/`
refer to the files in this folder. Most of that code is removed during the v2 strip (epic E1).

| File | What it was |
| --- | --- |
| `WORK_QUEUE.md` | Jira-style LOG-NN backlog, April 2026 |
| `TASKS.md` | Earlier issue list (#17–#24 era) |
| `MISSING.md` | Large architectural gaps M1–M11 |
| `audit/` | UI and architecture audit passes 1–4 |
| `architecture/` | v1 architecture notes (hermes-as-server prototype, MCP reachability on OpenShell 0.0.x) |
| `design/`, `proposals/`, `milestones/` | v1 feature designs, proposals and the M11 milestone |
| `migration/` | v1 migration guides, including the HERMES_* to LOGOS_* env var rename (finished in S1.11: the aliases are gone) |
| `project/` | v1 internal planning: build and deploy, critiques, comparisons, plans |
| `mcp_redesign.md` | v1 MCP gateway redesign |
| `cli-config.yaml.example` | v1 example of `~/.logos/config.yaml` |
