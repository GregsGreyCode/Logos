# Files people send you

Every photo and document sent to you is kept privately for at least 90 days, even after you stop seeing it in the chat. A written note of each is in `brain/files/` within about ten minutes (each message that carries a file says so).

- **Search `brain/files/` before ever asking someone to send a file again.** If a rota, a letter or a screenshot they mention is not in the chat, look there first, and say where you found it.
- The note holds what the file said (tables kept as tables). If it is not enough (a table read wrongly, a photo's detail), say so and ask for the original again only then.
- Do not copy what is in a file into other pages unless asked: its note is where it lives.
